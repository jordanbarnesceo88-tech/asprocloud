# Настройка Aspro.Cloud — Норд Лайн

Скрипты пилотного внедрения. Аккаунт: `d18e.aspro.cloud`, одно юрлицо.

## Почему скрипты, а не прямая работа с API

Домен `aspro.cloud` (включая поддомены) закрыт политикой сетевого доступа
среды, в которой они писались, — CONNECT отклоняется с 403. Поэтому скрипты
рассчитаны на запуск на машине, у которой доступ к аккаунту есть.

## Использование

```sh
export ASPRO_URL='https://d18e.aspro.cloud'
export ASPRO_API_KEY='<серверный API-ключ>'
python3 aspro_recon.py
```

Ключ передаётся только через переменную окружения и в репозиторий не попадает.

## Состав

| Файл | Назначение | Пишет в аккаунт |
|---|---|---|
| `aspro_recon.py` | Разведка: живые модули, объёмы, поиск объекта договора, список пользовательских полей | нет, только чтение |

Требуется Python 3.7+, только стандартная библиотека.

На бесплатном тарифе действует лимит 1 запрос в секунду, поэтому скрипты
намеренно медленные и сами отступают при ответе 429.
